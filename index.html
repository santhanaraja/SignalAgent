SignalAgent

A personal swing-trading decision system that turns trader discretion into computed rules: it reads the market’s regime, scans a GICS universe for leadership, grades each setup, tracks every holding’s exit and re-entry state, and enforces position limits in real dollars. It runs as the MarketPulse web service, re-baked by GitHub Actions every 15 minutes of the US session.

This page is the map: what was built, what was tested, what each test concluded, where every file lives. Index written 10 November 2026 against commit dcd8567. Every link is relative — open this file from the repo root and they resolve. Sources: the goal is docs/NORTH-STAR.md; the service is render.yaml; the schedule is update-signals.yml.

Where the record stands. The live system was built between February and July 2026, and its regime gauge was rebuilt once on evidence: Build 4 showed the first gauge would have kept you out of the market for nine of eleven years, and Gauge B replaced it on 17 July. Then eight studies, seven of them pre-registered, tested the trading doctrine between 25 July and 16 August, and none adopted a change. The A+ grade’s forward returns run inverted (A+ 0.83 < B 1.15 < C 1.63, mean % over 20 days); the systems replay found the doctrine “unfalsified but unsupported”; the extension guard, profit targets, exits and sizing each closed without a change. The joint D-011 + D-019 ruling those studies fed is still owed. Since then the work has been operating the system: a hand-kept ledger of real fills (50 closed rows and 4 open holdings at dcd8567), and order automation built to a shadow stage that places nothing.

7Running things

The app, locally

python3 ticker_api.py              # what Render runs; binds $PORT or 5002

One pipeline pass

./run_pipeline.sh                  # signal_engine, fear_greed_engine, history_manager
./run_pipeline.sh --serve          # the same, then serves public/ on :8080 (no /api)
bash scripts/bake.sh --no-notify   # the CI bake as one unit; --no-notify is for retries
python universe_builder.py --force # the Saturday rotation, by hand

The pins

python3 scripts/run_pins.py                                        # the whole suite
python3 scripts/run_pins.py test_pool_builder.py test_grade_view.py  # a subset

Each pin file runs in a fresh interpreter; the runner reports what the suite dirtied and restores nothing. The doctrine behind the pins is docs/testing.md.

The ledger

python3 scripts/close_position.py --ticker GEN --exit-date 2026-08-18 --exit-fill 27.66 \
    --fees 0.16 --exit-reason discretionary --fill-source broker_statement \
    --capital 97500 --regime-at-exit "Risk-on / Trending" --overrides "..." --dry-run
python3 scripts/add_entry.py --ticker NVDA --shares 27 --entry-price 230.76 \
    --entry-date 2026-10-01 --entry-stop 223.1252 --note "..." --dry-run
python3 scripts/frame_stop.py --ticker GEN --entry-date 2026-08-12

The examples are the scripts’ own docstrings. add_entry.py warns: close before you add.

No credential is on this page. The workflows read theirs from GitHub Actions secrets (update-signals.yml); the order path is gated by ops/automation_switch.json, which reads as killed unless it says exactly "off".
