BUILD 5B PRE-REGISTRATION — decision rules, written before
results.

A difference between arms COUNTS only if it (1) exceeds the
random-K selection-noise band, and (2) holds in sign across the
{0,5,15} bps cost range. Differences failing either test are
reported as inconclusive, not as findings.

Primary metric: expectancy per unit of risk (R). Secondary: max
drawdown. Raw CAGR is reported but is not the deciding metric.

1. If S1/S2 beat S3 AND S4 on expectancy-per-R and drawdown,
   despite Layer A's raw-return inversion → THE DOCTRINE SURVIVES
   as a risk-shaping filter. Hard gate stays. D-020 narrows to
   fixing the YTD penalty's sign and its calendar-anchored window.
2. If S3 beats S1/S2 on both expectancy-per-R and drawdown → THE
   HARD GATE DIES. Grades demoted to descriptive; B permitted in
   all regimes; A+ may survive as a sizing input, not a
   permission slip.
3. If S4 dominates S1/S2/S3 on expectancy-per-R → THE ENTRY
   DOCTRINE IS REPLACED, NOT REPAIRED. D-011 superseded; D-020
   becomes the entry rule; the replacement gets its own frontier
   sweep before it goes near live capital.
4. If NO arm beats SPY buy-and-hold on risk-adjusted terms →
   ENTRY SELECTION IS NOT THE EDGE. The chassis and the stops
   are. Simplify toward fewer gates; keep the drawdown machinery.
5. If all arm differences sit inside the random-K band → THE
   DOCTRINE IS UNFALSIFIED BUT UNSUPPORTED. The hard gate softens
   to advisory by default: an unproven restriction should not
   bind live capital.
6. If the headline verdict is not robust across all three
   selection orderings (score / random-K / native), the report
   says so and the ruling is DEFERRED pending a selection-rule
   deliberation — the selection rule would then be the finding.
