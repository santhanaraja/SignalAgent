# Reference pages

Styled, self-contained explainers for the operator. Written from
source, not inferred; each page states what a thing IS and what the
studies FOUND. HTML pages are the styled copies; open them raw or
serve the folder locally — nothing in production serves this
directory.

## Orientation

| page | what it covers |
|---|---|
| [glossary.html](glossary.html) | Every build, arm, scorer version, decision record and rule identifier — each with its VERDICT, not just its name. Current through Build 5.2. |
| [surfaces-explained.md](surfaces-explained.md) / [.html](surfaces-explained.html) | Dashboard vs framework: YTD, the score, all six "signal" quantities, and the nine places the two surfaces disagree. The .md renders on GitHub; the .html is the styled copy. |
| [grades-complete.html](grades-complete.html) | The A+/B/C rule from source: all seven rows, the five score ladders, seven traps. Supersedes the earlier grades-explained draft, which was not committed. |
