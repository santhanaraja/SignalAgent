A+, B and C — every test, every threshold, every operator

Seven rows decide the grade. Row 1 is itself five conditions, and row 5 is a composite score built from five ladders. This page carries all of it — the tests, the constants, the comparison operators, and the places where those operators disagree with each other. Read from source, nothing inferred.

1 · The grade itself

Four branches in fixed order. The first match wins, so one C-row failure outranks any number of B-row failures.

# position_signals.py:433
failing = [k for k, r in rows.items() if not r["met"]]

if not rows["1_conditions"]["met"] or not rows["2_extension"]["met"]:
    grade = "C"
elif not rows["3_approach"]["met"] and not appr_unavailable:
    grade = "C"
elif failing:
    grade = "B"
else:
    grade = "A+"

# :380 — appr_unavailable = close is None or sma5 is None
A fourth outcome the ladder never produces: grade: null. Four causes — missing or non-finite core inputs, a row with no grade inputs, a per-candidate exception, and inputs computed under different knobs. Null-grade dicts have a different shape — three keys, no failing list — so any consumer assuming failing exists will KeyError on exactly the ungradeable rows.
Holdings are never graded. The block is gated on kind == "watching". The grade is an entry doctrine only — once you own a name the stop governs it and no grade is computed.

2 · Row 1 — the five mechanical conditions

All five live in assess_position. Row 1 passes only if all five do, and row 1 is C-escalating — so any one of these failing sends the name straight to C.

conditionexact testnotes
1 trigger close > sma20 Strict. close == sma20 is NOT met.
2 confirmation closes_above >= 2
OR
close > sma20 + 0.5 × ATR14		 Two independent satisfiers. Either two consecutive closes above the SMA20, or a single close more than half an ATR above it. The counter breaks on a NaN SMA, capping it during warm-up; the display clamps to the minimum, so nine consecutive closes prints "2/2".
3 regime gate exact string equality Three modes, no permissive default — see below.
4 slope sma20 >= sma20_5d_ago No tolerance, no epsilon. Equality passes. The 5-day lookback is chosen at the call site — inside the function the parameter affects only the printed text.
5 thesis bool(group_in_universe) Fails closed on a full outage (no group, no universe, no signals). But an unmapped name passes, flagged — with a consequence, below.
The regime gate matches exact strings and has no permissive default. "Risk-on / Trending" → full, passes. "Risk-on / Choppy" → conditional, passes and arms the A+-only hard gate. Everything else — including any typo — is "blocked", fails, and takes the whole grade to C. That is the correct fail direction, but it means a malformed regime string would silently grade the entire board C.
The unmapped-group trap, live on ARWR. A watcher with no group mapping passes condition 5 with a flag — but its group is then None, so row 6's breaker lookup returns None, row 6 fails, and the grade is capped at B. The same missing fact passes one row and fails another.

Row 3's "up-close off the swing low", precisely: take the last 20 bars, find the lowest close in that window (first occurrence on ties), and require at least one strictly positive close-to-close change from that bar forward. If the low is the most recent bar there is nothing after it and the test is False.

4 · Row 5's composite score — the whole formula

Five components summed onto a base of 50, then clamped. Nothing else feeds it.

score = clamp(0, 100, 50 + rsi + macd + ma + ytd + vol)

Raw values span −5 to +107, so both clamps bind — 0 and 100 are each reachable. Every component returns an integer, so the score always is one.

YTD two ladders — see below The component D-020a changed.
Degradation defaults are not neutral. A missing RSI scores +3, a missing MACD scores −8, and missing moving averages score −14. A data outage does not produce a neutral score — it produces a bad one.
The score bands use the opposite convention from every point ladder. Bands are inclusive >= — 75 strong-buy, 60 buy, 45 hold, 30 sell — while every ladder above uses strict comparisons that push boundaries downward. Two conventions, one number.
Where the numbers live. All seven row thresholds sit in config. None of the score ladders do — they are module constants and inline literals. Changing a score band is a code change, not a configuration change.

5 · The YTD component — v1 versus v2

D-020a replaced the over-extension penalty with a flat cap. The two ladders agree completely up to 50% and diverge sharply above it.

All comparisons are strict, so boundaries fall to the lower band — YTD exactly 20 gives +6, exactly 50 gives +12. Reachable values are v1 {−10, −7, −4, −2, +2, +6, +8, +12} and v2 {−10, −4, +2, +6, +12}.

If a worked example shows ytd: −7, it is a v1 score and does not describe production. That value is producible only by the frozen ladder, and only above 150% YTD. Live SNDK at 421% YTD scores +12 under v2 for a total of 64; the same frame under v1 gives −7 for a total of 45. Same tape, nineteen points, different band.

6 · Row 4 can never decide a grade

The RSI row is B-escalating. It has also never once been the reason a name was graded, and the arithmetic explains why.

Its B verdict comes from three non-observational sources: a direct call of the real function; the 848,328-row backtest frame, where row 4 fails alone 1,772 times and grades B in all 1,772; and the pins. The artifact record cannot settle it and essentially never could.

7 · Seven traps

Places where the code does something the rule as stated does not imply. All verified by direct call.

trapwhat happens
Row 7 passes on bad dates An unparseable earnings date becomes None, and None passes row 7 as unbounded runway. On this runtime date.fromisoformat accepts only YYYY-MM-DD, so a timestamped date raises and silently becomes a pass — inverting the "A+ is proven, never presumed" convention rows 4, 5 and 6 follow.
Row 2 grades unrounded The row tests the raw extension while the display shows it rounded to two places. A displayed "1.80×" can be a failing 1.80004.
RSI 70 collides Exactly 70 passes row 4 (inclusive) and simultaneously scores −8 in the ladder (because rsi < 70 is False). Same number, opposite sides, two rows.
Row 4's RSI isn't the shown RSI Row 4 uses Wilder RSI on the confirmed frame; the dashboard's RSI comes from the scorer on the live frame. They can differ mid-session.
NaN is not None Row 3's carve-out tests is None only. A NaN SMA5 grades as a proven knife → C, not as missing data.
The hard gate adds no state Under Choppy a non-A+ name is blocked at the render — but the artifact still says RE_ENTRY_READY. Reading the state without also reading the grade gate gives the wrong answer. B blocks identically to C, and an ungradeable name is blocked too.
Grades are yesterday, prices are now Every graded scalar is as of the last confirmed close while the price, RSI and score printed beside it are live. The forming bar splits at 16:10 ET, not 16:00 — the closing auction.

Three things to carry elsewhere

Other graders exist and are not this one. The backtest's grade-lite drops condition 5 from row 1, hardwires the breaker to clear, uses the v1 YTD ladder, and demotes A+ to B on an earnings coverage gap. Another study variant disables row 2 entirely. Both of those are C-branch rows — so any "B or better" figure quoted from a study is not this rule's B.

Withholding is surface-dependent. The ticker view returns no grade at all for an off-universe name, for a missing or degraded breaker, and via three separate insufficient-data exits. The candidate tier grades those same names — row 6 simply fails and they land at B. The same ticker can be "no grade" on one surface and "B" on another, and both are correct.

Two documents currently describe this wrongly. The grade_setup docstring says "rows 4–6 fail → B", omitting row 7, and claims row 3 escalates in every regime with no carve-out. The A+ doctrine brief carries the pre-amendment rule in which the approach knife grades B — the rule amendment 1 overturned — with no superseded banner. The D-011 decision record itself is correct.
