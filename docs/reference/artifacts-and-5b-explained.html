1 · How a question becomes law

Every artifact type is one station on this loop. Colour = who writes it. Nothing skips a station: a rule that never became a decision record isn't a rule, and a decision without pins isn't enforced.

2 · What Build 5B actually is

A controlled experiment. Five strategies run over the same six years with the same money, the same stop, the same sizing and the same costs — the only difference is who is allowed in the door. Then everything is measured a second and third time under different door-queue rules, because the queue turned out to matter.

Why R-multiples instead of returns. Layer A asked "what happened next?" and the doctrine lost. But the doctrine never promised big wins — it promised cheap losses: an A+ entry sits within 1.8×ATR of a rising SMA20, so the stop is close and being wrong is small. R normalises for that. One unit of R is one unit of money risked, so a strategy that wins less but risks far less can still win on expectancy-per-R. That is the doctrine's entire remaining case, and this is the measurement that either grants it or ends it.

3 · The amendment that needed a diagram — why S4 needs its own queue rule

On most days more names qualify than there are slots, so a queue rule decides who actually gets bought. Using the composite score as that rule looks neutral. It isn't — the score contains the YTD penalty, which docks names for extreme momentum. So score-ordering quietly demotes the highest-momentum names inside the momentum arm.

Same trap, caught twice. Claude Code spotted this shape for S5 — without a close > SMA20 requirement, the shared stop would instantly eject every S5 entry and the baseline would be a strawman. It missed the identical problem one row over in S4. That's why the queue rule now runs three ways: score-order for realism, random-K as the neutral null, native order so no arm is tested handicapped.

4 · The pre-registration — deciding what the answer means, before it exists

Layer A was easy to accept because it indicted us. 5B is the dangerous one: it's the doctrine's last chance, so every ambiguous result will be tempting to read as vindication. This table is committed first, in its own commit, so the ruling is a lookup rather than an argument.
